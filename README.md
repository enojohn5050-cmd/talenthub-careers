# TalentHub Careers

A premium, responsive job application experience built with HTML, CSS, and JavaScript.

## Features

- Responsive careers landing page
- Premium modern UI
- Accessible form labels
- Native form validation
- Focus, valid, invalid, hover, and checked states
- Custom availability radio controls
- Interactive application success message
- Mobile responsive layout
- Semantic HTML structure

## Project structure

```text
talenthub-premium/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Note

The application form is currently a frontend demonstration. It does not send application data to a real backend.
